# 水电点位维护规则

用户要求所有点位展开详情必须显示数量、安装高度等参数，后续变更持续遵守。

- 点位事实从 `review_points.py` 及其导入的修订模块生成；不要直接编辑 `src/data.json`。
- 每个点位必须在 `point_specs.py` 中维护 `quantity`、`quantityStatus`、`height`、`heightStatus`、`basis`，以及与实际安装位置一致的 `location`、测量口径和每个标签的数量。
- 新增、删除、合并或移动点位时，同步复核数量、分处数量、总数、高度和核量说明；位置来源、用户已确认值、附件建议及机型待定必须区别表达。
- 未确定的数量或高度必须明确写待定/待核定及条件，不可留空、默认为1个或编造施工数值。数量区分供电位置、插座个数、面板、接口和设备；编号数不是插座数。
- 一个编号有多个图上标签时，详情同时表达本处数量与本组合计。关联的设备接口不一定是同一底盒；门口与床头面板分别计量，电源与控制功能不得重复算电源。
- 所有高度以mm表达，标明距完成地面的测量口径；参考图未说明中心/边缘的情况需注明现场核对。顶面供电、柜内设备、燃气报警器等按设备/柜体/气种条件核定，不强制套用常规高度。
- 同步更新气泡、完整清单、浏览器CSV、`deliver.py`导出的CSV和离线HTML。保留原附件原文作为对照。
- GitHub Pages 发布源为仓库 `main:/docs`；`npm run build` 会同步该目录。提交发布更新时一并包含 `docs/`，保持分享页面与当前方案一致。
- 运行 `python3 review_points.py`、`npm run check`、`npm run build`、`python3 deliver.py`；检查参数完整性、数量与多标签对应关系，并在浏览器验证。修改Ant Design组件时按ant-design技能先查询API、再执行lint。
- 3D使用`src/modelData.ts`从同一份2D数据生成标记；保留原编号。厨房柜体使用V9，柜内适配参考M1；K01按用户要求保留冰箱背后。三维示意标高不能回写成已确认施工参数。
- 更新3D后验证立体、俯视、四面正视和剖切遮挡；正视仅标记对应面的接口。构建与导出同时覆盖`model.html`和离线三维HTML。
